## 줄거리 요약

공항 재회 → 지하철 지도로 시드니 지리 학습 → 열차 이동 중 밀린 이야기 → 서큘러키에서 내려
더 록스 골목의 작은 편집숍 발견(포인트 부족으로 구경만) → 서큘러키에서 사진 찍고 관광 →
옷값을 벌자며 갑작스러운 낚시 제안 → 낚시로 첫 수익 → 숙소 도착·저녁 식사 →
충전기 꽂으려다 폰 분실 → 냉장고 틈에서 폰, 환기구에서 정체불명의 황동 열쇠("M.K.") 발견 →
집주인에게 전화하지만 정체는 밝혀지지 않음 → 첫날 밤 마무리. 이 열쇠가 4주 전체 미스터리의 시드.
