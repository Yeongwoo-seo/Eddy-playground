## 0. 지수·영우 외 인물 보이스 요약

지수·영우는 `voice-bible-v2.md`를 그대로 따른다. 그 외 인물은 짧은 발화·즉각 반응 원칙은 공유하되, 지수·영우의 말버릇(`ㅎㅎㅎㅎㅎㅎ`, `!!!`, `개쥬아`, `샤갈` 등)은 사용하지 않는다.

| 인물 | 말투 요약 |
|---|---|
| 다니엘 리드 | 표준어에 가까운 매끄러운 반존대. 문장이 짧고 정돈되어 있으며 과장이 없다. 4단계(친절한 가이드→목격자→고집→총책)에 따라 점점 문장이 짧아지고 감정이 빠진다. |
| 레오 박 | 편한 반말, 살짝 어눌하고 웃음이 많음(“어..”, “아니 그게”). 심문이 진행될수록 말이 끊기고 존댓말이 섞여 나온다. |
| 윤민아 | 빠른 말투, SNS 용어 섞음(“컷”, “클립”, “업로드”). 초반엔 방어적·날카롭고, 혐의를 벗은 뒤엔 실무적으로 돕는 톤. |
| 클레어 모건 | 사무적이고 정확한 존댓말. 바쁠 때 문장이 짧아짐. 2부에서 자책할 때 존댓말이 흔들린다. |
| 소피 첸 | 편안한 반말 섞은 존댓말, 수다스럽고 정이 많음. 기억을 더듬을 때 문장이 느려진다. |
| 애드리언 콜 | 지나치게 예의 바른 존댓말, 질문을 질문으로 받아치며 얼버무림. 2부에서 협조적으로 바뀌면 문장이 짧고 직접적으로 변한다. |
| 마틴 베일(전화) | 나이 든 장인의 신중한 존댓말, 문장이 길고 뜸을 들인다. |
| 관광객 NPC | 짧고 캐주얼한 대사, 개인차 있음(국적·성격을 대사 한두 줄로만 암시). |
