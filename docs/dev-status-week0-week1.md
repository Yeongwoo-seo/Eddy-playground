**줄거리 요약**: 공항 재회 → 지하철 지도로 시드니 지리(공항/시티/숙소=Eastwood/영우 직장=Marayong) 학습 → 열차 이동 중 밀린 이야기 → 숙소 도착·저녁 식사 → 짐 정리 중 핸드폰 분실 → 미니게임으로 냉장고 틈에서 폰, 환기구에서 정체불명의 황동 열쇠(각인 "M.K.") 발견 → 집주인에게 전화하지만 정체는 밝혀지지 않음 → 첫날 밤 마무리. 이 열쇠가 4주 전체 미스터리의 시드.

### 미니게임 상태

- **`/dev/minigame-phone-search/`** (냉장고 틈=폰, 환기구=열쇠+갈고리 조합): 완성도 높음. 4개 실사진 기반 핫스팟, 아이템 조합 2종, 강제 이벤트 체인까지 실제 구현되어 있고 대사와도 정합됨.
- **`/dev/minigame-eastwood/`** (지도 미니게임): **알려진 불일치 있음.** 대사/`minigameStages`는 4개 지점(공항·시티·숙소·직장) 기반 "라벨 배치+관계 연결+경로 표시" 설계를 설명하지만, 실제 구현은 여전히 예전 3단계("공항→Eastwood→Marayong 순서대로 탭") 방식(`minigame-eastwood/index.html` `STAGES`, 시티 단계 없음). 코드 내 주석으로 "follow-up 구현 필요"라고 명시적으로 플래그되어 있음. 플레이는 가능하지만 대사가 약속하는 것보다 단순함.

### 케이스 파일 연동
- 증거 1건 등록: `evidence-accommodation-keycard` (숙소 카드키)
- 질문 1건 등록: `question-key-hunch` (선택지에 따라 "불길한 느낌" / "순수한 궁금증" 두 버전)
- 열쇠 자체의 정식 증거 등록(`evidence-unknown-key`)은 1주차로 넘어감

### 총평
스코프상 짧고 기믹이 적은 프롤로그 주차라는 점을 감안하면 **사실상 완성**. 대부분 씬이 v3/v4로 이미 개정을 거쳤고, 두 미니게임 모두 플레이 가능한 승리 조건이 있음. 유일한 실질 갭은 지도 미니게임의 4곳 설계 vs 3단계 구현 불일치.

## 알려진 이슈 / 후속 작업 목록

1. **지도 미니게임 불일치** (0주차) — `/dev/minigame-eastwood/`가 여전히 3단계 순서 찾기 방식. 대사가 설명하는 4곳 라벨배치/관계연결/경로표시 설계로 재구현 필요.
2. **1→2주차 이름 연속성 이음매** — 1주차는 "M.K." 계정 단서까지만 노출하고 전체 이름을 절대 밝히지 않도록 개편되었으나, `week2-scene-012`는 여전히 "미카 코바치 — M.K. 가능성 65%" 같은 확정적 표현을 그대로 씀. 2주차 개편이 아직 반영 안 된 상태로 코드에 명시적으로 플래그되어 있음.
3. **평일 미니씬 전체 주차 공통 미구현** — 0~4주차 모두 주말/메인 아크만 있고 W-D1~D5 평일 파트는 아직 없음.
4. **문서 드리프트(사소함)** — 1주차 상단 주석에 "마틴 베일 통화·애드리언 재심문 아직 없음"이라고 적혀 있으나 실제로는 `week1-scene-011a`/`011b`로 이미 구현되어 있음. 기능 문제는 아니고 주석 갱신 누락.
