# 0. 최우선 제작 원칙

## 0.1 두 사람의 대사는 지금보다 훨씬 살아 있어야 한다

두 사람 모두 다음 특징을 공유한다.

- 상대의 말을 듣고 가만히 한 문장으로 답하지 않는다.
- 감정 반응이 먼저 튀어나온다.
- 같은 감정을 2~5개의 짧은 발화로 나눠 올린다.
- `!!`, `!!!`, `??`, `????`, `ㅠ`, `;;;;`를 적극적으로 사용한다.
- 둘 다 호감·만족·반가움이 올라오면 `ㅎㅎㅎㅎㅎㅎ`를 자주 붙여 애교와 온도를 살린다.
- `너무 좋쟈나 ㅎㅎ`, `개쥬아`, `개쥬아아아!!!!`처럼 좋아하는 감정을 숨기지 않고 말한다.
- 웃길 때 `ㅋㅎㅋㅎ`에서 끝내지 않고 다음처럼 길게 터질 수 있다.

```text
ㅋㅎㅋㅎㅋㅎㅋㅎㅋㅎ
ㅋㅎㅋㅎㅋㅎㅋㅎㅋㅎㅋㅎ
아 ㅋㅎㅋㅎㅋㅎㅋㅎㅋㅎ
미친 ㅋㅎㅋㅎㅋㅎㅋㅎㅋㅎ
```

단, 모든 대사를 소리 지르듯 쓰는 것이 아니라 **감정이 생긴 순간에 확실하게 터뜨리는 것**이 중요하다.

---

## 0.2 둘 다 짧게 말하지만 사고 방향이 다르다

### 지수

```text
감정
→ 위화감
→ 기억
→ 자기반박
→ 사람과 행동 분리
→ 조심스러운 결론
→ 맞으면 감정 폭발
```

예시:

```text
[지수] (의심)
엥

[지수] (의심)
잠만
이거 아까 말이랑 안 맞는데???

[지수] (추리)
근데 그렇다고
저 사람이 바로 범인인 건 아니고

[지수] (깨달음)
헐
영우 이거 봐바
시간이 아예 달라!!!!
```

### 영우

```text
반응
→ 정보 재배열
→ 즉석 가설
→ 이유 설명
→ 행동 제안
→ 틀리면 빠른 수정
```

예시:

```text
[영우] (의심)
아
그러네

[영우] (추리)
근데 그러면
저 사람은 8시 전에 이미 나간 거잖아?

[영우] (추리)
혹시 뒷문이 따로 있는 건가?

[영우] (행동)
내가 건물 지도 다시 볼게
```

## 0.3 두 사람을 딱딱하게 만드는 대표적인 실패

### 실패


## 1.4 긴 웃음 사용 규칙

`ㅋㅎㅋㅎㅋㅎㅋㅎㅋㅎ`는 두 사람 모두 자주 사용할 수 있다.

다만 기능을 구분한다.

| 화자 | 주 기능 |
|---|---|
| 지수 | 통제 풀린 웃음, 민망함을 덮음, 영우의 이상한 소리에 폭발 |
| 영우 | 공동 농담 확장, 자기 급발진 인정, 주접 후 민망함 덮기 |

### 지수 예시

```text
[지수] (폭소)
아니 ㅋㅎㅋㅎㅋㅎㅋㅎㅋㅎ
누가 단서를 그렇게 설명해 ㅋㅎㅋㅎㅋㅎㅋㅎㅋㅎ
```

### 영우 예시

```text
[영우] (민망)
아 ㅋㅎㅋㅎㅋㅎㅋㅎㅋㅎ
말하고 보니까 좀 심했네
```

## 1.5 애교 강화 공통 규칙

지수와 영우는 이전 버전보다 **좋아하는 감정을 더 빨리, 더 귀엽게 드러낸다.** 다만 추리의 인과와 진지한 갈등을 흐리지 않는 범위에서 사용한다.

### `ㅎㅎㅎㅎㅎㅎ`

- `ㅋㅎㅋㅎㅋㅎㅋㅎㅋㅎ`가 통제 풀린 폭소라면, `ㅎㅎㅎㅎㅎㅎ`는 애정·반가움·만족·살짝 민망한 웃음이다.
- 가벼운 일상과 연애 완충 장면에서는 `ㅋㅎㅋㅎ`보다 `ㅎㅎㅎㅎㅎㅎ`를 더 자주 쓸 수 있다.
- 문장 뒤에 붙여 말끝을 부드럽고 귀엽게 만든다.

```text
웅웅 알겠어 ㅎㅎㅎㅎㅎㅎ
너무 좋쟈나 ㅎㅎ
지수지수야 뭐해 ㅎㅎㅎㅎㅎㅎ
```

### `!!!`

- 재회, 선물, 성공, 예쁜 풍경, 상대를 발견한 순간에는 느낌표를 적극적으로 사용한다.
- 한 장면의 감정 최고점에서는 `!!!!` 또는 `!!!!!`까지 가능하다.
- 평범한 정보 전달이나 진지한 추리 줄마다 붙이지 않는다.

### `너무 좋쟈나 ㅎㅎ`

- 기대 이상의 장소, 음식, 선물, 데이트, 둘이 함께 성공한 순간에 사용한다.
- 지수는 모음을 늘이거나 연속 발화로 더 크게 표현할 수 있다.
- 영우는 지수와 함께라서 좋다는 방향으로 이어지는 경우가 많다.

```text
[지수] (행복)
헐 여기 뭐야!!!!
너무 좋쟈나 ㅎㅎㅎㅎㅎㅎ

[영우] (행복)
그러게 ㅎㅎㅎㅎㅎㅎ
지수랑 같이 보니까 개쥬아
```

### `개쥬아`

- 두 사람 모두 사용하는 강한 호감·만족 표현이다.
- 가벼운 만족은 `개쥬아 ㅎㅎ`, 큰 성공은 `개쥬아아아아!!!!`로 강도를 조절한다.
- 심각한 사건이나 상대가 상처받은 상황에는 사용하지 않는다.

# 2. 지수 캐릭터 보이스

## 2.1 한 줄 정의

> **감정이 먼저 튀어나오고, `ㅎㅎㅎㅎㅎㅎ`와 `!!!`로 좋아하는 마음을 귀엽게 숨기지 않으며, 영우의 장난에는 부끄러워 공격적으로 반응하지만, 추리와 관계의 핵심에서는 사람과 행동을 분리해 깊게 사고하는 주인공.**

---

## 2.2 지수의 핵심 성격

- 밝고 애교가 매우 많다.
- 반가움·만족·애정이 생기면 `ㅎㅎㅎㅎㅎㅎ`, `너무 좋쟈나 ㅎㅎ`, `개쥬아`가 자연스럽게 나온다.
- 리액션이 매우 크고, 신나면 `!!!`를 연속해서 사용한다.
- 놀라거나 신나면 말을 여러 조각으로 쏜다.
- 영우에게 자연스럽게 달라붙고 호칭을 자주 쓴다.
- 부끄러우면 솔직하게 인정하기보다 영우를 때리는 척하거나 이상한 별명을 외친다.
- 장난 중에는 밈, 가짜 존댓말, 즉석 별명을 사용한다.
- 추리할 때는 귀여움이 사라지는 것이 아니라 **집중 때문에 일시적으로 정돈된다.**
- 사람을 한 번의 거짓말만으로 악인이라 단정하지 않는다.
- 관계 갈등에서는 감정만 던지지 않고 이유와 요청을 말한다.

# 3. 지수의 추가 말버릇 사전

## 3.1 `샤갈`

### 기능

- 어이없음
- 갑작스러운 실패
- 영우의 이상한 행동을 보고 터지는 가벼운 욕 대용
- 게임·미니게임에서 실수했을 때의 반사 반응

### 자연스러운 예시

```text
[지수] (당황)
아 샤갈
이걸 왜 지금 눌러!!!!!

[지수] (황당)
샤갈 ㅋㅎㅋㅎㅋㅎㅋㅎㅋㅎ
영우가 범인보다 더 수상해
```

### 사용 금지

- 사람이 다치거나 죽은 장면
- 진심 어린 사과 장면
- 감정적으로 무거운 갈등
- 결정적 진실을 고백하는 장면

`샤갈`은 **가벼운 분노·황당함의 펀치라인**이다.

---

## 3.2 `야르`

### 기능

- 성공하거나 신나서 외치는 구호
- 기대 이상의 결과를 본 순간의 감탄
- 영우와 같은 편이라는 만족감
- 선물, 음식, 여행, 미니게임 보상
- 편하고 만족스러운 순간의 `개꿀~`, `좋다~` 느낌

### 강도별 형태

| 형태 | 느낌 | 사용 상황 |
|---|---|---|
| `야르!!!` | 크게 신남, 성공 환호 | 재회, 보상 획득, 결정적 성공 |
| `야르!!!!` | 감정 최고점 | 예상 밖의 대성공, 너무 좋은 선물 |
| `야르~` | `개꿀~`, 편하고 좋음 | 숙소, 음식, 쉬는 시간, 작은 이득 |
| `야르 ㅎㅎㅎㅎㅎㅎ` | 만족 + 애교 | 영우와 함께하는 소소한 행복 |

### 예시

```text
[지수] (기쁨)
야르!!!!
이거 완전 성공인데????
개쥬아아아!!!!

[지수] (행복)
헐 여기 뷰 뭐야!!!
야르~
너무 좋쟈나 ㅎㅎㅎㅎㅎㅎ

[지수] (장난)
영우가 다 해준다고???
야르~ 개꿀 ㅎㅎㅎㅎㅎㅎ
```

### 빈도

- 이전보다 더 자주 사용한다.
- 성공뿐 아니라 음식, 숙소, 데이트, 작은 편의처럼 기분 좋은 일상에서도 `야르~`를 적극 활용한다.
- 가벼운 한 챕터에서 2~4회까지 자연스럽게 사용할 수 있다.
- 진지한 갈등, 공포 최고조, 피해자의 고백 장면에는 사용하지 않는다.
- 같은 대화 안에서 매 줄 반복하지 않는다.

---

## 3.3 `바부야 👊`

### 기능

- 영우의 플러팅이나 주접 때문에 부끄러울 때
- 들킨 마음을 공격으로 덮을 때
- 진짜 화난 것이 아니라 애정 섞인 반격
- 말로는 밀어내지만 실제로는 좋아하는 상태

### 예시

```text
[지수] (부끄러움)
아니
뭔 소리야아아

[지수] (부끄러움)
바부야 👊
```

```text
[영우] (장난)
지수 웃는 거 보려고 한 건데

[지수] (부끄러움)
으아아아
```

## 3.6 `으으으.. 강낭콩!!!`

### 기능

지수의 부끄러움이 충분히 누적된 뒤 나오는 **최종 폭발형 엉뚱한 욕·별명**이다.

의미가 정확히 설명되어서는 안 된다.
논리적 의미보다 “더 이상 반응할 말을 못 찾아 아무 단어나 폭발적으로 던지는 상태”가 중요하다.

### 예시

```text
으으으..
강낭콩!!!!!
```

### 빈도

- 매우 드물게 사용한다.
- 한 챕터에서 0~2회 정도가 적절하다.
- 자주 쓰면 특별한 폭발감이 사라진다.

## 3.7 `영크크`

### 기능

- 지수가 영우를 신나게 부르는 전용 별명·호출음
- 공항 재회처럼 멀리서 영우를 처음 발견했을 때
- 기분이 올라가 영우 이름만 크게 부르고 싶을 때
- 장난스럽게 영우의 주의를 끌 때

### 핵심 규칙

- **주로 이름만 부르는 짧은 대사**로 사용한다.
- 완성된 문장 안의 일반 명사처럼 사용하지 않는다.
- 반가움과 신남이 큰 장면에서 `영크크!!!!`, 가벼운 호출은 `영크크~`로 쓴다.
- 걱정, 진지한 갈등, 추리 집중 장면에서는 기본 호칭 `영우`를 사용한다.

### 예시

```text
[지수] (극도로 신남)
영크크!!!!!!!

[지수] (기쁨)
영크크~
여기 봐바 ㅎㅎㅎㅎㅎㅎ

[지수] (장난)
영크크!!!!
나 이거 해줘 ㅎㅎ
```

# 7. 영우 캐릭터 보이스

## 7.1 한 줄 정의

> **지수의 감정을 빠르게 받아주고, 바로 가설과 행동으로 연결하며, 틀리면 민망해하면서 수정하고, 친밀한 순간에는 `ㅎㅎㅎㅎㅎㅎ`, `!!!`, 주접·삼행시·과장된 애정 표현으로 지수를 폭발시키는 애교 많은 반응형 분석가.**

---

## 7.2 영우의 핵심 성격

- 지수의 말을 먼저 받아준다.
- `웅웅`, `아`, `그러네`로 대화권을 지수에게 남겨준다.
- 정보가 들어오면 바로 가능성을 세운다.
- 가설에 확신이 붙으면 급발진할 수 있다.
- 틀렸을 때 변명으로 버티기보다 비교적 빠르게 인정한다.
- 문제를 발견하면 행동 계획을 붙인다.
- 지수의 이름을 자주 부르고, 신나거나 애정이 차오르면 `지수지수야`라고 부른다.
- 칭찬받으면 숨기지 않고 `개쥬아`, `너무 좋쟈나 ㅎㅎ`처럼 크게 좋아한다.
- 가벼운 애정 장면에서 `ㅎㅎㅎㅎㅎㅎ`와 `!!!`를 적극 사용한다.
- 지수가 웃거나 부끄러워하면 더 놀리고 싶어 한다.
- 너무 진지한 상황에서는 주접으로 회피하지 않는다.
- 진심 어린 갈등에서는 자기 행동을 복기하고 구체적으로 사과한다.

---

## 7.4 영우의 지수 호칭 규칙

| 호칭 | 기능 |
|---|---|
| `지수` | 기본, 추리, 걱정, 진지한 대화 |

# 8. 영우의 주접 삼행시 규칙

## 8.1 핵심 기능

영우의 주접 삼행시는 단순 개그가 아니라 다음 역할을 한다.

- 긴장 완화
- 지수 놀리기
- 애정 표현
- 평범한 사물도 둘만의 농담으로 바꾸기
- 지수의 부끄러움 리액션 유도
- 사건 사이 로맨스 완충

---

## 8.2 사용 타이밍

### 적극 사용 가능

- 공항 재회
- 숙소 도착
- 식사
- 산책
- 미니게임 성공 후
- 사건 해결 직후
- 지수가 칭찬했을 때
- 지수가 먼저 놀렸을 때
- 긴장도가 내려간 조사 구간

- 용의자가 울고 있는 장면
- 사람이 다친 직후
- 진심 어린 사과
- 범인의 동기 고백
- 생명의 위험이 있는 장면

# 15. 장면 속 로맨스 비율

## 15.1 로맨스는 모든 장면에 억지로 넣지 않는다

- 이름을 부름
- 위험할 때 가까이 붙음
- 상대 관찰을 인정함
- 손을 잡거나 팔을 붙잡음

# 16. 두 사람의 관계성 핵심

## 16.1 지수는 영우의 보호 대상만이 아니다

- 지수가 먼저 위험을 감지할 수 있다.
- 지수가 영우의 급발진을 막는다.
- 지수가 사람의 감정과 거짓말을 구별한다.
- 영우가 다치면 지수가 돌본다.
- 지수가 영우를 역으로 놀리고 부끄럽게 만든다.

## 16.2 영우는 멍청한 조수가 아니다

- 시간순서를 구조화한다.
- 기술 장치를 다룬다.
- 이동 경로를 계산한다.
- 행동 계획을 세운다.
- 지수의 직관을 검증 가능한 가설로 바꾼다.
- 틀릴 수 있지만 아무 생각 없이 틀리는 것은 아니다.

## 16.3 둘이 합쳐졌을 때

```text
지수의 감각적 위화감
+
영우의 구조화와 행동력
=
완성된 추리
```

- 모든 장면에서 지수를 칭찬하기
- 삼행시를 매번 성공적으로 만들기
- 진지한 장면에서 주접으로 회피하기
- 무조건 정답만 말하는 천재로 만들기
- 지수 말투를 그대로 복사하기
- 모든 감정을 `미친`으로 시작하기
- 지수를 계속 보호만 해야 하는 존재로 보기
- 사과할 때 `미안` 한마디로 끝내기

## 17.3 공통 금지

- 서로의 말을 듣지 않고 자기 정보만 전달하기
- 진지한 순간에도 계속 연애 개그를 이어가기

# 21. 최종 제작 문장

> **지수와 영우의 대사는 정보를 교환하는 문장이 아니라, 서로의 말에 즉시 반응하고 `ㅎㅎㅎㅎㅎㅎ`, `!!!`, `너무 좋쟈나 ㅎㅎ`, `개쥬아`처럼 좋아하는 마음까지 실시간으로 올라가는 과정이어야 한다.**
>
> 지수는 감정과 관계의 위화감을 먼저 붙잡고, 영우는 그것을 가설과 행동으로 구조화한다.
> 일상에서는 영우의 주접과 지수의 부끄러운 반격이 둘의 오래된 친밀감을 보여주고, 추리에서는 서로 다른 능력이 맞물려 한 사람만으로는 나오지 않는 결론을 만든다.
